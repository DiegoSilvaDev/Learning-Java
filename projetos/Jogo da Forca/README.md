# Projeto Jogo da Forca

Wireframe (rascunho) Jogo da Forca

```text
	Palavra: [_, _, _, _, _]
	Chute uma letra: u

	Você tem mais 5 tentativas.
	Palavra: [_, _, _, _, _]

	Chute uma Letra: c
	Palavra: [c, _, _, _, _]

	... jogo continuando

	Palavra: [c, o, b, _, a]
	Chute uma letra: r

	Parabéns, você acertou! A palavra era: cobra

```

## Funcionalidades

- O jogo deve rodar no terminal.
- Seleciona aleatoriamente uma palavra secreta (Exemplo: "cobra", "elefante", e "girafa").
- Exibe a palavra oculta com traços representando as letras não descobertas.
- Permite ao jogador fazer chutes de letras.
- Atualiza a exibição da palavra oculta conforme as letras são acertadas.
- Informa o número de tentativas restantes.
- Finaliza o jogo quando a palavra é completamente descoberta ou quando as tentativas se esgotam.
