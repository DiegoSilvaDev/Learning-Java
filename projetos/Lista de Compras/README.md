# Projeto Lista de Compras

Wireframe (rascunho) Lista de Compras

```text
+------------------------------------+
| Lista de Compras 					 |
+------------------------------------+
| Digite o item que deseja adicionar |
| [ ________________ ] 				 |
| 									 |
| +-------------------+ 			 |
| | Adicionar 		  | 			 |
| +-------------------+ 			 |
| 									 |
| Lista de Compras: 				 |
| +-------------------+ 			 |
| | Item 1 			  | 			 |
| | Item 2 			  | 			 |
| | Item 3			  | 			 |				
| | ... 	  		  | 			 |
| +-------------------+ 			 |
| 									 |
| +-------------------+ 			 |
| | Exportar Lista    | 			 |
| +-------------------+ 			 |
| 									 |
+------------------------------------+

```

### Componentes do Aplicativo

1. **Campo de Texto**: Os usuários poderão digitar o nome do item que desejam
adicionar à lista.
2. **Botão "Adicionar"**: Ao clicar neste botão, o item digitado será adicionado à lista
de compras.
3. **Lista Visualizável**: Exibirá os itens da lista de compras em formato de lista.
4. **Botão "Exportar Lista"**: Ao clicar neste botão, os itens da lista serão
exportados para um arquivo de texto chamado "listaDeCompras.txt".
