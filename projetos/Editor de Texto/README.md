# Projeto Editor de Texto Básico

Wireframe (rascunho) Editor de texto Básico

```text
+----------------------------------+
| Editor de Texto				   |
+----------------------------------+
| [Salvar]						   |
| 								   |
| 								   |
+----------------------------------+

```

### 1. Objetivo:

Criar um editor de texto simples usando `JavaFX`. O programa
permite digitar, editar e salvar texto em um arquivo.

### 2. Componentes:

- **TextArea**: Área para digitar e editar o texto.
- **Botão "Salvar"**: Abre uma janela para escolher onde salvar o arquivo de texto.

### 3. Compilação com Dependências Transitivas: 

```bash
javac --module-path "Caminho" --add-modules javafx.controls ProjetoEditorTexto.java`
```
