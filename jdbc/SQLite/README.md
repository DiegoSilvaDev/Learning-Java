# SQLite

## O que é o SQLite?

**SQLite** é um sistema de gerenciamento de banco de dados relacional simples e eficiente.

### Principais características do SQLite

1. Leve e Portátil
2. Sem Configuração
3. Código aberto
4. Desempenho

### Quando usar o SQLite?

O SQLite é ideal para:

- Aplicações móveis (Android e IOS).
- Aplicações de desktop.
- Pequenos websites.
- Aplicações embarcadas.


## Configuração do SQLite

#### O que são esses arquivos e sua importância

1. `slf4j-api-1.7.13.jar`: **Arquivo da API do SLF4J(Simple Logging Facade for Java).**
2. `slf4j-simple-1.7.13.jar`: **Este é um dos módulos de implementação do SLF4J.**
3. `sqlite-jdbc-3.46.0.0.jar`: **Driver JDBC para SQLite.**

#### Compilação e Execução

Estes arquivos fornecem as funcionalidades necessárias para logging e acesso ao banco de dados SQLite.
