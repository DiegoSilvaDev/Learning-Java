
# ☕ Java 

Repositório dedicado ao meu aprendizado em Java, reunindo estudos teóricos, exercícios práticos e projetos desenvolvidos ao longo da minha evolução na linguagem.

O objetivo é consolidar os fundamentos da programação, aprofundar os conhecimentos em orientação a objetos e avançar para o desenvolvimento de aplicações back-end com Java e Spring Boot.

## Objetivos

- Consolidar os fundamentos da linguagem Java.
- Aprofundar os conhecimentos em Programação Orientada a Objetos (POO).
- Praticar estruturas de dados, Collections, Generics e Streams.
- Aprender a trabalhar com bancos de dados e SQL.
- Desenvolver APIs REST com Spring Boot.
- Aplicar boas práticas de programação e organização de código.
- Construir projetos práticos para consolidar os conhecimentos e compor meu portfólio.
