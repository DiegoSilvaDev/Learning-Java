# Loops (laços)

Os loops (laços) usados para repetir um bloco de código varais vezes.

Exemplo: 

```java
for (int i = 0; i < 5; i++) {
	System.out.println("O valor de i é: " + i); // primeiroRetorno = 0
}
```

## Explicação

O laço `for` em Java é usado para repetir um bloco de código, um número conhecido de vezes, seguindo a sintaxe `for (inicialização; condição; incremento) { bloco de código }`.

- **Inicialização** `(int i = 0)`: Cria e define o valor inicial da variável de controle.
- **Condição** `(i < 5)`: O laço roda enquanto essa expressão for verdadeira.
- **Incremento** `(i++)`: Aumenta o valor de `i` em 1 a cada volta do loop (laço).
