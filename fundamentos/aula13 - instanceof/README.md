# Controle de Fluxo

## Instruções Condicionais em Objetos

- `instanceof`:

```java
Object obj = "Hello";

if(obj instanceof String) {
	System.out.println(obj); // Saída: Hello
}
```

## Explicação

- `instanceof`:

	Serve para verificar se um objeto é uma instância de uma classe específica, subclasse ou interface, retornando um valor booleano (`true` ou `false`)
