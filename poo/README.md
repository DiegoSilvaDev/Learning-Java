# POO - Programação Orientada a Objetos

A Programação Orientada a Objetos (POO) é um modelo ou padrão de desenvolvimento de software baseado na criação e na interação entre "objetos" que representam elementos do mundo real.

*O Java é uma linguagem de programação orientada a objetos, de alto nível e fortemente tipada, baseada no princípio "escreva uma vez, execute em qualquer lugar" por meio da [Java Virtual Machine (JVM).](https://azure.microsoft.com/pt-br/resources/cloud-computing-dictionary/what-is-java-programming-language)*

## Conceitos Básicos

- **Classe**: É a planta ou o molde (por exemplo, a classe `Carro`) que define quais dados e comportamentos os objetos daquele tipo terão.
- **Objeto**: É a instância concreta criada a partir de uma classe (por exemplo, um carro específico com cor vermelha e ano 2024).
- **Atributos**: São as características ou propriedades que guardam o estado do objeto (como cor, modelo e marca).
- **Métodos**: São as ações ou funções que o objeto pode executar (como `acelerar()` ou `frear()`).

## Os 4 Pilares da POO

- **Encapsulamento**: Protege os dados internos do objeto, controlando o acesso a eles por meio de métodos específicos (como getters e setters).
- **Herança**: Permite que uma classe herde atributos e métodos de outra, facilitando a reutilização de código (por exemplo, uma classe Moto herdando de Veículo).
- **Polimorfismo**: Permite que métodos herdados sejam reescritos ou executados de formas diferentes, dependendo do objeto que os chama.
- **Abstração**: Esconde a complexidade dos processos internos, mostrando apenas o que é essencial para o uso daquele objeto.
