# Packages java (pacotes)

## Pontos importantes:

1. **Organização**
2. **Prevenção de conflitos de nomes**
3. **Reutilização de código**
4. **Controle de acesso**

### Exemplo: 

```java
	package empresa.dados; //Declaração de pacote

	public class Funcionarios {

		// Seu código

	}
```

## Explicação

Um pacote (`package`) em Java é um **espaço de nomes** (`namespace`) que serve para agrupar classes, interfaces e subpacotes relacionados, funcionando de forma semelhante às **pastas e diretórios** no sistema operacional do seu computador.
