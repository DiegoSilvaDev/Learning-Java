# `List` interface

- Package java.util.list --> `import java.util.list`

- Elementos duplicados

- Exemplo: `ArrayList` implementa `List`

```java
	// Criando uma lista

	List<String> lista = new ArrayList<>();

	lista.add("Java");

	lista.add("Python");

	lista.add("C++");

	System.out.println("Conjunto: " + lista);
```
