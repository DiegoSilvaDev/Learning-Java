# Set interface

- Package java.util.set --> `import java.util.set`

- Sem duplicatas

- Exemplo: `HashSet` implementa `Set`

```java
	// Criando um conjunto

	Set<String> conjunto = new HashSet<>();

	conjunto.add("Java");

	conjunto.add("Python");

	conjunto.add("C++");

	System.out.println("Conjunto: " + conjunto);
```
